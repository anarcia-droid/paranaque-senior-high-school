# Parañaque Senior High School Website

A responsive, single-page school information website built with HTML, CSS and JavaScript.

## Preview locally
Open index.html in a web browser.

## Publish with GitHub Pages
1. Open repository Settings > Pages.
2. Under Build and deployment, select Deploy from a branch.
3. Select branch main and folder / (root), then Save.
4. Wait for GitHub Pages to finish publishing.

The site uses placeholder school information where official details have not been verified. Replace these sections with school-approved content before treating the site as official.
